# example

## Структура проекта

```
.
├── README.md          # описание проекта и инструкции
└── site/
    ├── index.html     # главная страница сайта с перечнем учебников
    ├── textbooks/     # отдельные страницы и материалы учебников
    └── styles/
        └── main.css   # общие стили сайта
```

## Как открыть сайт

1. Соберите содержимое репозитория (build не требуется).
2. Откройте файл `site/index.html` в браузере. Это можно сделать двойным кликом по файлу или через контекстное меню «Открыть с помощью…».
3. Убедитесь, что все относительные пути сохраняют структуру, чтобы ссылки и стили работали корректно.

## Как добавить новый учебник

1. Создайте файл с содержимым учебника в директории `site/textbooks/`. Рекомендуется использовать HTML или Markdown, который затем конвертируется в HTML.
2. Добавьте карточку или ссылку на новый учебник в `site/index.html`, чтобы он отображался на главной странице.
3. При необходимости обновите навигацию и списки разделов, чтобы пользователям было проще найти новый материал.

## Обновление стилей

* Все глобальные стили хранятся в `site/styles/main.css`.
* Для изменения оформления компонентов обновляйте соответствующие селекторы в этом файле.
* Если требуется добавить уникальный стиль только для одного учебника, создайте дополнительный CSS-файл рядом с его страницей и подключите его в HTML.
